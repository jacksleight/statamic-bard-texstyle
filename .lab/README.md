# Bard Texstyle Lab

Development lab for [`jacksleight/statamic-bard-texstyle`](../statamic-bard-texstyle), pulled in over a composer path repository so edits in the package are live here.

Runs at http://statamic-bard-texstyle--lab.test/ (Herd parks `~/Packages`). Log in at `/!/skip/admin`.

One collection, `tests`, with an entry per feature. Each has its own blueprint and its own template, which renders the Bard output twice: as HTML, and as escaped source.

See `CLAUDE.md` for the full layout.
